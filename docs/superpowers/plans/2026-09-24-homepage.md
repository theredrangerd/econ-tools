# IB Econ Graph Site — Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and locally previewable-deploy the site's homepage — hero, search, and a tiered bento grid of the four IB syllabus units, each linking to a generic "coming soon" stub page with an embedded feedback form.

**Architecture:** A Vite multi-page site (real `.html` files per page, no client-side router) with plain vanilla JS (no TypeScript, no UI framework — keeps tooling minimal for a solo maintainer). Small, independently-testable JS modules (`units` config, `search` filter, `chrome`/`bento` DOM renderers) are wired together by thin per-page entry scripts. Design tokens (colors/fonts) are lifted verbatim from `equilibrium-lab.html`'s `:root` CSS variables into a shared stylesheet so the new pages match its aesthetic exactly.

**Tech Stack:** Vite 5, Vitest + jsdom for unit tests, vanilla JS (ES modules), plain CSS (custom properties, CSS Grid). No framework, no backend.

**Spec:** `docs/superpowers/specs/2026-09-24-ib-econ-graph-site-design.md`

## Global Constraints

- No UI framework (React/Vue/Svelte etc.) — plain Vite + vanilla JS only.
- Multi-page mode: each page is a real `.html` file; no client-side router.
- Shared chrome (header/hero/nav) is injected via JS, not copy-pasted markup, per page.
- Bento tiering is a **fixed config value**, never computed from live graph count: Microeconomics = large, Macroeconomics = medium, International = small, Development = small.
- All four unit tiles currently point to one generic "Work in Progress" stub page (not real subpages — those don't exist yet).
- Feedback form embed URL (exact, from spec): `https://docs.google.com/forms/d/e/1FAIpQLSc4hUwcytl1QE3H1Iod7Ag8SRmmgDdEAPJED37kbj-ZB2O7yQ/viewform?usp=publish-editor`
- Typography/color tokens must match Equilibrium Lab exactly: Source Serif 4 (headings), IBM Plex Sans (body), IBM Plex Mono (eyebrow/mono labels); full light/dark theme support via the same CSS custom properties.
- "Coming soon" units are visible on the homepage, never hidden or omitted.
- This plan covers the **homepage only**. Real unit subpages, individual graph pages, analytics, and the GitHub Pages deploy workflow are explicitly out of scope (see spec's "Open / not yet designed").

## Review Focus

- Bento tiles must be real `<a href>` elements, not click-handler-only `<div>`s — otherwise keyboard navigation, right-click "open in new tab," and screen readers all break silently. (Task 7)
- An empty/whitespace-only search query must show all units, not an empty or broken result set. (Task 5)
- A search query that matches nothing must show an explicit "no results" message, not a silently empty grid that looks broken. (Task 8)
- Visiting the work-in-progress page with no `?unit=` param, or an unrecognized one, must show a generic sensible heading — not `undefined` or a blank page. (Task 9)
- Search must match case-insensitively and on partial words inside tags (e.g. "wage" should find the unit tagged "minimum wage"), not just an exact/prefix match on the unit's name. (Task 5)

- [ ] **Step 3: Write `src/components/search.js`**

```js
export function filterGraphs(query, items) {
  const q = query.trim().toLowerCase();
  if (q === '') return items;
  return items.filter((item) => {
    const haystack = [item.name, ...(item.tags || [])].join(' ').toLowerCase();
    return haystack.includes(q);
  });
}
```

import { renderMiniHeader } from '../components/chrome.js';
import { getUnits } from '../lib/units.js';

const FEEDBACK_FORM_URL =
  'https://docs.google.com/forms/d/e/1FAIpQLSc4hUwcytl1QE3H1Iod7Ag8SRmmgDdEAPJED37kbj-ZB2O7yQ/viewform?usp=publish-editor&embedded=true';

export function resolveUnitName(search, units) {
  const params = new URLSearchParams(search);
  const slug = params.get('unit');
  const match = units.find((u) => u.slug === slug);
  return match ? match.name : 'This section';
}

export function initWipPage(doc, location) {
  const headerEl = doc.querySelector('#mini-header');
  const titleEl = doc.querySelector('#wip-title');
  const formEl = doc.querySelector('#feedback-form');

  const units = getUnits();
  const unitName = resolveUnitName(location.search, units);

  renderMiniHeader(headerEl, { title: unitName });
  titleEl.textContent = `${unitName} is coming soon`;
  formEl.src = FEEDBACK_FORM_URL;
}
